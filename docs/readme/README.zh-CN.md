# Alfred workspace

开发与维护： **[Alfredlabs](https://alfredlabs.org)**.

用于编程代理、终端、Git worktree 和文件夹的工作空间，支持本地和远程开发环境。

[GOI17/alfred-workspace](https://github.com/GOI17/alfred-workspace)

## 开发

需要 Node.js 24+ 和 pnpm。命令为 `alfred`，配置使用 `ALFRED_*`。这是独立安装，不会自动迁移原有数据或凭据。

```sh
pnpm install
pnpm dev
```
