# Alfred workspace

Desarrollado y mantenido por **[Alfredlabs](https://alfredlabs.org)**.

Espacio de trabajo para agentes de programación, terminales, worktrees de Git y carpetas, tanto locales como remotos.

[GOI17/alfred-workspace](https://github.com/GOI17/alfred-workspace)

## Desarrollo

Requiere Node.js 24+ y pnpm. El comando es `alfred`; la configuración usa `ALFRED_*`. Es una instalación independiente: no migra automáticamente datos ni credenciales anteriores.

```sh
pnpm install
pnpm dev
```
