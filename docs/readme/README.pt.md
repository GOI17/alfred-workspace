# Alfred workspace

Desenvolvido e mantido por **[Alfredlabs](https://alfredlabs.org)**.

Um espaço de trabalho para agentes de programação, terminais, worktrees Git e pastas, locais ou remotos.

[GOI17/alfred-workspace](https://github.com/GOI17/alfred-workspace)

## Desenvolvimento

Requer Node.js 24+ e pnpm. O comando é `alfred`; a configuração usa `ALFRED_*`. Esta instalação independente não migra automaticamente dados nem credenciais anteriores.

```sh
pnpm install
pnpm dev
```
