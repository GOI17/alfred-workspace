# Alfred workspace

Développé et maintenu par **[Alfredlabs](https://alfredlabs.org)**.

Un espace de travail pour les agents de programmation, les terminaux, les worktrees Git et les dossiers, en local ou à distance.

[GOI17/alfred-workspace](https://github.com/GOI17/alfred-workspace)

## Développement

Node.js 24+ et pnpm sont requis. La commande est `alfred` ; la configuration utilise `ALFRED_*`. Cette installation indépendante ne migre pas automatiquement les données ni les identifiants existants.

```sh
pnpm install
pnpm dev
```
