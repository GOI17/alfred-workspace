The Alfred CLI is the `alfred` command-line interface for scripting a running Alfred editor from any shell. Use it to create and inspect worktrees, drive agent terminals, open files and diffs, automate the built-in browser, run scheduled automations, share HTML/Markdown artifacts, and control Alfred-native tools from scripts or AI agents.

It ships with the desktop app; register it under [Settings → General → Alfred CLI](/docs/settings). On Linux the command is `alfred-ide`, because GNOME Alfred's screen reader already owns `/usr/bin/alfred` — see [Install → Linux](/docs/install#linux).

Agents can install the matching Alfred CLI skill with:

```bash
npx skills add https://github.com/GOI17/alfred-workspace --skill alfred-cli
# headless / no Settings UI:
alfred skills install --skill alfred-cli
```

See [Skills registry & MCP](/docs/cli/skills) for every installable Alfred skill, including `alfred skills install` / `alfred skills update`.

## Install & verify

```
command -v alfred
alfred status --json
```

## Worktree commands

```
alfred worktree ps --json
alfred worktree create --repo id:<repoId> --name my-task --issue 123 --json
alfred worktree current --json
alfred worktree set --worktree active --comment "reproduced bug" --json
alfred worktree rm --worktree id:<id> --force --json
```

For selectors, setup flags, parent/child worktrees, and the broader command map, see [Alfred CLI reference](/docs/cli/reference).

## Terminal commands

```
alfred terminal list --json
alfred terminal read --json
alfred terminal send --text "continue" --enter --json
alfred terminal wait --for tui-idle --timeout-ms 30000 --json
alfred terminal create --worktree path:/projects/app --command "npm test" --json
alfred terminal split --direction vertical --command "npm run dev" --json
```

For tracked multi-agent work, use [Orchestration](/docs/cli/orchestration) instead of plain terminal prompts.

## File commands

Open files and diffs in the active Alfred worktree from a shell:

```
alfred file open src/App.tsx
alfred file diff src/App.tsx --staged
alfred file open-changed --mode both
```

Use `--worktree <selector>` when the shell's current directory is not inside the target worktree.

## Browser profiles

Browser profiles isolate tab session state, so a script or agent can test with different cookies, local storage, and logged-in identities. The CLI exposes profile commands under `alfred tab profile`; start with `alfred tab profile list --json`, then use `create`, `set`, `clone`, or `use-default` as needed.

## Scheduled automations

Use `alfred automations` to create, inspect, run, and remove scheduled Alfred tasks from a shell. Start with [Scheduled automations](/docs/cli/automations) when you want a recurring prompt to run against a repo or an existing worktree.

## Artifacts

Share HTML or Markdown as public view links through the signed-in Alfred account (`alfred artifacts share|update|list|delete`). Publishing is **opt-in** under Settings → Artifacts. Command details: [CLI reference → Artifacts](/docs/cli/reference#artifacts).

## Browser automation

The CLI also drives the built-in browser with a snapshot-interact-re-snapshot loop:

```
alfred goto --url https://example.com --json
alfred snapshot --json     # returns refs like @e1, @e3
alfred click --element @e3 --json
alfred fill --element @e1 --value "user@example.com" --json
alfred screenshot --json
```

For responsive browser checks, switch the active tab to a named device profile:

```
alfred set device --name "iPhone 12" --json
alfred screenshot --json
```

## Mobile emulator

The CLI can also drive an iOS Simulator through Alfred's mobile emulator bridge. It is scoped to the active worktree, so agents and scripts can attach a simulator from `alfred emulator list`, tap normalized coordinates, type text, send gestures, rotate the device, and shut it down without leaving Alfred.

```
alfred emulator list --json
alfred emulator attach "<device-name-or-udid>" --json
alfred emulator tap 0.5 0.7 --json
alfred emulator type "hello" --json
alfred emulator gesture '[{"type":"begin","x":0.5,"y":0.8},{"type":"move","x":0.5,"y":0.4},{"type":"end","x":0.5,"y":0.2}]' --json
alfred emulator rotate landscape_left --json
alfred emulator kill --json
```

Use `--worktree <selector>`, `--device <udid-or-name>`, or `--emulator <id>` when a script needs an explicit target.
